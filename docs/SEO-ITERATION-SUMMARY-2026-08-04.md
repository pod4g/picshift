# SEO 迭代总结（2026-08-04）

本轮重新按历史复盘标准导出 Google Search Console 的 24 小时、7 天、28 天和 3 个月四个窗口，并保留查询、网页、国家/地区、设备、搜索结果呈现、图表和过滤器七张原始 CSV。原始文件与口径说明归档在 [`gsc-export-2026-08-04`](./gsc-export-2026-08-04/README.md)。

Semrush 仅用于观察外部权威趋势，其流量、关键词和涨幅均为第三方估算，不作为页面实验的直接因果证据。

## 核心结论

- 中期增长仍然成立：最近 28 天相对前 28 天，点击增长 26.4%，展示增长 18.7%，平均排名从 12.32 改善到 12.07；
- 最近一周进入增长后的平台期：展示环比增长 5.5%，但 CTR 从 0.94% 降至 0.76%，使点击下降 14.7%；这不是收录崩塌或全站排名系统性倒退；
- `/es/webp-to-jpg` 是本轮最明确的机会：最新 24 小时获得 1,105 展示、平均排名 9.76，却没有点击，保留 title-only 实验；
- `/ru/image-compressor` 的精确查询长期处于前十附近但 CTR 很低，保留 title-only 实验；`/ru/webp-to-jpg` 的 description-only 实验未达标，按预设规则回滚；
- `/ja/image-compressor` 以及俄语 HEIC 赢家继续冻结；当前数据不支持增加 RU authority pin、批量重写页面或同时叠加更多实验。

## 数据限制

- GSC 标准界面的查询导出最多 1,000 行；7 天、28 天和 3 个月查询表分别覆盖全站约 78.1%、75.1% 和 70.5% 的展示，以及约 62.9%、60.4% 和 59.0% 的点击；
- 查询表和网页表是分开的全站聚合数据，当前导出没有 `query × page × country × device` 联合维度，因此“页面核心查询”属于由语言、意图和趋势做出的高可信推断，不能当作已验证的逐页归因；
- 24 小时数据是滚动窗口，最后一个小时尚未完成且数据可能被 Google 修订，只用于发现最新脉冲；
- 四个搜索结果呈现 CSV 均只有表头，本批数据无法判断富结果表现；页面表的展示可能因同一次搜索出现多个页面或锚点而高于图表总量。

下一次实验复盘应先对目标页面使用精确 URL 过滤，再分别导出查询、国家和设备；如需严格分析蚕食或设备结构，应使用 Search Console API 导出联合维度。

### 技术卫生

| 范围 | 改动 |
|---|---|
| 404 页面 | 增加 `noindex, follow`，移除不存在的多语言 hreflang，并补随机不存在路径返回 404 的回归测试 |
| PWA | 不再预缓存 405 个 HTML 页面，改为访问时按需缓存，减少首次访问后的后台下载量 |

本轮明确不增加俄语 authority pin。现有实现会在 12 个俄语转换页中各挤掉一个同输出格式的 HEIC 链接，累计削弱 `/ru/heic-to-png`、`/ru/heic-to-webp` 等赢家的站内入链，不符合“保护赢家”和单变量原则。

## 实验保护线与复盘口径

1. 部署当天记录真实上线时间，并保存部署前四窗口基线；
2. 7 天后只确认 Google 是否重新抓取页面、搜索结果是否开始采用新标题或摘要，不根据短窗口波动继续改文案；
3. `/es/webp-to-jpg` 在 14 天后按页面过滤后的固定查询、国家和设备复盘；排名需保持前 15，CTR 目标为从约 0.1% 提升到至少 0.5%；
4. `/ru/image-compressor` 在 14 天仅做安全检查，累计至少 1,000–1,500 次实验后展示或部署满 28 天后再结案；核心查询排名保护线为 8–11 附近，CTR 目标为从 0.27% 提升到至少 0.8%；
5. `/ru/webp-to-jpg` 在 14 天仅做安全检查，部署满 28 天或达到足量展示后再判断；排名只作为不跌出前 15 的保护线，成功标准是同排名区间下 CTR 改善，而不是排名本身；
6. 实验期内不修改上述页面的其它 meta、H1、正文或内链；`/ja/image-compressor`、`/ru/heic-to-png` 和快速增长的 `/ru/heic-to-jpg` 继续冻结。

## 已知技术债

- 最终 HTML 审计仍报告 131 条 title/description 长度提示；Google 没有固定字符数硬限制，且当前存在 ES/RU 页面实验，因此这些提示保持非阻断并留待页面过滤后的 GSC 证据逐项处理；
- `/ru/image-compressor` 的现有 description 为 193 字符，超过 Playbook 的 165 字符上限；为了保持 title-only 可归因，本轮不同时修改，待实验结案后单独处理；
- Search Console API 实际导出仍取决于 quota project 启用 API 和只读 OAuth 授权；代码、请求口径和失败恢复已完成验证，但未擅自修改外部 Google Cloud 配置。
