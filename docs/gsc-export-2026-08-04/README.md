## 口径限制

- GSC 标准界面导出的查询表最多返回 1,000 行，因此“完整导出”指界面允许的完整标准导出，而不是无上限查询明细；

- 24 小时数据是滚动小时窗口，且可能继续被 Google 修订，只用于观察最新脉冲，不单独触发 SEO 改动；
- 7 天用于观察短期变化，28 天用于判断实验，3 个月用于确认趋势与避免季节性误判；
- 查询、页面、国家和设备分别聚合，不能从本批 CSV 直接还原 `query × page × country × device` 联合维度；
- 四个时间窗口的 `搜索结果呈现.csv` 都只有表头，没有可分析的数据行；页面、国家和设备表可能因聚合方式、隐私阈值与匿名查询而无法与查询表逐行完全对账。
